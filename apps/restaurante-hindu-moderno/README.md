# Restaurante Hindú Moderno

Landing local para Restaurante Hindú Moderno, cocina india casera en Plaza Nuestra Señora de la Victoria, Rincón de la Victoria (Málaga).

## Comandos

- `bun run dev` — servidor Astro local.
- `bun run test` — pruebas locales de datos y contenido.
- `bun run check` — validación Astro.
- `bun run typecheck` — comprobación de TypeScript.
- `bun run build` — generar sitio estático.

## Datos públicos usados

- Nombre: Restaurante Hindú Moderno.
- Dirección: Plaza Nuestra Señora de la Victoria, 29730 Rincón de la Victoria, Málaga.
- Teléfono: +34 608 13 88 74.
- Cocina: india/hindú casera. Ofrece opciones vegetarianas, picante ajustable y servicio para llevar y a domicilio.

Los platos listados en el panel "Los más pedidos" son los que más se repiten en reseñas públicas de la ficha (Chicken Tikka Masala, Cordero Rogan Josh, Biryani de pollo, Malai Kofta y naan). No se incluyen horarios, precios ni valoraciones.

## Sobre la foto

La URL de Google Maps facilitada es **solo la ficha del lugar** y no contenía ninguna foto
(le faltaba el segmento `!6shttps://lh3.googleusercontent.com/...`). Por eso este sitio **no
hotlinkea ninguna imagen** y resuelve la portada con tipografía y un panel de carta.
Si quieres añadir una foto real, pega la URL de la imagen y se incorpora al hero (y a
`og:image` / `twitter:image`).

La URL canónica (`https://restaurante-hindu-moderno-malaga.vercel.app`) es provisional: cámbiala
si el sitio se despliega en otro dominio, y actualiza también `public/robots.txt` y `astro.config.mjs`.

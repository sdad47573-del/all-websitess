# El Anzuelo Restaurante · Córdoba

Landing Astro con diseño adaptable, SEO local, datos estructurados, especialidades, galerías externas y reservas telefónicas.

## Desarrollo

Desde la raíz del monorepo:

```sh
bun install --filter el-anzuelo-restaurante
bun --filter el-anzuelo-restaurante dev
```

Validación: `bun --filter el-anzuelo-restaurante check`, `typecheck` y `build`.

El enlace de Maps proporcionado identifica la ficha y coordenadas, pero no contiene URLs directas a archivos de fotos. La web enlaza las galerías reales de Maps y redes oficiales. Las ilustraciones SVG son originales y están identificadas como gráficos, no como fotografías del establecimiento.

La dirección y el teléfono (+34 661 73 79 22) aparecen en los perfiles oficiales y varios directorios. La selección gastronómica es orientativa; la carta y disponibilidad cambian. Confirma horarios, platos y alérgenos con el restaurante.

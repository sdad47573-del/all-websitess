# Restaurante La Vianda de María

Sitio estático en Astro para La Vianda de María, restaurante de cocina cordobesa en Avenida Doctor Fleming, 1, Córdoba.

## Comandos

Desde la raíz del monorepo, después de enlazar las dependencias del workspace:

- `bun run --cwd apps/restaurante-la-vianda-de-maria dev` — iniciar Astro en local.
- `bun run --cwd apps/restaurante-la-vianda-de-maria check` — validar páginas Astro.
- `bun run --cwd apps/restaurante-la-vianda-de-maria typecheck` — comprobar TypeScript.
- `bun run --cwd apps/restaurante-la-vianda-de-maria build` — generar el sitio estático y su sitemap.

# Restaurante Baldomero

Sitio Astro para Restaurante Baldomero, cocina tradicional cordobesa en Avenida de Cádiz, 20, Aldea Quintana, La Carlota.

## Comandos

Desde la raíz del monorepo, una vez enlazadas sus dependencias:

- `bun run --cwd apps/restaurante-baldomero dev` — iniciar Astro.
- `bun run --cwd apps/restaurante-baldomero check` — validar las páginas.
- `bun run --cwd apps/restaurante-baldomero typecheck` — comprobar TypeScript.
- `bun run --cwd apps/restaurante-baldomero build` — generar el sitio estático y el sitemap.

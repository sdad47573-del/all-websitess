# Restaurante Damasco

Sitio Astro para Restaurante Damasco, restaurante sirio en Calle Romero, 4, Córdoba.

## Comandos

Desde la raíz del monorepo, después de enlazar sus dependencias:

- `bun run --cwd apps/restaurante-damasco dev` — iniciar Astro.
- `bun run --cwd apps/restaurante-damasco check` — validar las páginas.
- `bun run --cwd apps/restaurante-damasco typecheck` — comprobar TypeScript.
- `bun run --cwd apps/restaurante-damasco build` — generar el sitio estático y su sitemap.

## Fotografías

El enlace de Google Maps facilitado identifica la ficha del restaurante, pero no contiene la URL de un archivo fotográfico. El sitio muestra el mapa y enlaza a las galerías originales de Google Maps, Facebook e Instagram. La imagen social `public/og.svg` es una ilustración original, no una fotografía del local.

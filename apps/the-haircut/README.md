# The Haircut

Landing local para The Haircut & Sunbody, peluquería, barbería y centro de bronceado en Teatinos, Málaga.

## Desarrollo

Desde esta carpeta, con las dependencias del monorepo instaladas:

- `bun run dev` — servidor de desarrollo Astro.
- `bun run test` — pruebas locales de datos y contenido.
- `bun run check` — comprobación de Astro.
- `bun run typecheck` — comprobación TypeScript.
- `bun run build` — generar el sitio estático.

La fotografía enlazada procede de la URL específica de Google Maps facilitada para el negocio. Verifica que siga disponible y que su reutilización sea adecuada antes de publicar.

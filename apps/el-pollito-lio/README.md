# El Pollito Lio

Landing local para El Pollito Lio, asador de cocina argentina (pollo al espiedo, milanesas y empanadas caseras) en Avenida del Mediterráneo, 16, Rincón de la Victoria (Málaga).

## Comandos

- `bun run dev` — servidor Astro local.
- `bun run test` — pruebas locales de datos y contenido.
- `bun run check` — validación Astro.
- `bun run typecheck` — comprobación de TypeScript.
- `bun run build` — generar sitio estático.

## Datos públicos usados

- Nombre: El Pollito Lio.
- Dirección: Avenida del Mediterráneo, 16, 29730 Rincón de la Victoria, Málaga.
- Coordenadas (ficha de Maps): 36.7158711, -4.2902975.
- Teléfono y WhatsApp: +34 605 91 98 12 — publicado por el propio local en su Instagram y repetido en directorios locales.
- Instagram: https://www.instagram.com/elpollitolio_rincon/
- Cocina: argentina / asador. Milanesas (napolitana, americana, fugazzetta), empanadas caseras, pollo asado al espiedo con patatas fritas, tequeños, sándwich de milanesa.
- Servicio: take away, servicio a domicilio y encargos. Reparto en Rincón de la Victoria, Torre de Benagalbón y La Cala del Moral.

No se incluyen horarios, precios ni valoraciones (aunque el local publica promociones, estas cambian cada día y no se replican aquí).

## Foto de Google Maps

La URL facilitada es solo la ficha del lugar: **no incluía ninguna foto** (le faltaba el segmento `!6shttps://lh3.googleusercontent.com/...`). Por eso el sitio no hotlinkea ninguna imagen y resuelve la portada con tipografía y un panel de "ticket" de pedidos. Si consigues una foto propia o autorizada, añádela al `hero` y define `og:image`.

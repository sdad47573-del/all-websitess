# AR Professional

Landing local para AR Professional, salón de peluquería y belleza unisex en Teatinos, Málaga.

## Comandos

- `bun run dev` — servidor Astro local.
- `bun run test` — pruebas locales de datos y contenido.
- `bun run check` — validación Astro.
- `bun run typecheck` — comprobación de TypeScript.
- `bun run build` — generar sitio estático.

La foto de portada usa el recurso concreto enlazado en la ficha de Google Maps facilitada. Confirma que siga disponible y que su reutilización sea adecuada antes de publicar.

# Barbershop Guillermo Val

Landing local para la barbería Barbershop Guillermo Val, en C. Castilla, Málaga.

## Comandos

- `bun run dev` — servidor Astro local.
- `bun run test` — pruebas de datos locales y contenido de la landing.
- `bun run check` — validación de Astro.
- `bun run typecheck` — comprobación TypeScript.
- `bun run build` — generar la web estática.

La fotografía de portada enlaza a la imagen específica de Google Maps facilitada. Confirma que el recurso siga disponible y que su reutilización sea adecuada antes de publicar.

# Restaurante a fuego lento

Landing local en Astro para Restaurante a fuego lento, en el Pasaje del Balcón de Lagartijo, nave 27, B2, Córdoba.

## Comandos

- `bun run dev` — servidor Astro local.
- `bun run check` — validación Astro.
- `bun run typecheck` — comprobación de TypeScript.
- `bun run build` — generar el sitio estático y el sitemap.

## Datos públicos incluidos

- Dirección: Pje. del Balcón de Lagartijo, nave 27, B2, 14014 Córdoba.
- Teléfono: +34 857 83 01 70.
- Horario publicado: lunes a viernes, 06:00–17:00; sábado y domingo, cerrado.
- Coordenadas de Google Maps: 37.9004127, -4.7307956.

La información se ofrece como referencia y puede cambiar; la página recomienda confirmar por teléfono.

## Fotos de Google Maps

La URL proporcionada es la ficha del negocio y no contiene una URL directa de imagen (`!6shttps://lh3.googleusercontent.com/...`). Por eso la página incorpora la ficha/mapa de Google Maps y enlaza a su galería original, en lugar de inventar fotos o usar imágenes de otro comercio.

La URL canónica `https://restaurante-a-fuego-lento.vercel.app` es provisional; actualízala si el dominio final es distinto, junto con `astro.config.mjs` y `public/robots.txt`.

# Pasillo Oriental · Córdoba

Landing Astro adaptable con SEO local, datos estructurados, cocina halal de Oriente Medio/Egipto, mapa y contacto.

## Desarrollo

Desde la raíz del monorepo:

```sh
bun install --filter pasillo-oriental
bun --filter pasillo-oriental dev
```

Validación: `bun --filter pasillo-oriental check`, `typecheck` y `build`.

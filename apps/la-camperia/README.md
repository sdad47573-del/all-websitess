# La Campería

Landing local para La Campería, bar de camperos malagueños en Calle Andrómeda, 15, Teatinos-Universidad (Málaga).

## Comandos

- `bun run dev` — servidor Astro local.
- `bun run test` — pruebas locales de datos y contenido.
- `bun run check` — validación Astro.
- `bun run typecheck` — comprobación de TypeScript.
- `bun run build` — generar sitio estático.

No se incluyen horarios, precios ni valoraciones.

## Qué NO se ha incluido (y por qué)

1. **Foto de Google Maps**: la URL facilitada es solo la ficha del lugar y **no contenía ninguna foto** (le faltaba el segmento `!6shttps://lh3.googleusercontent.com/...`). El sitio no hotlinkea ninguna imagen y resuelve la portada con tipografía y un patrón de rayas.
2. **Platos concretos**: no hay carta pública fiable de este local. En lugar de inventar platos, la sección "El campero" explica qué es el campero malagueño clásico y sus ingredientes habituales, con una nota invitando a preguntar en la barra.
3. **Redes sociales**: no se ha verificado ninguna cuenta oficial, así que no se enlaza `sameAs`. Ojo: existe otro "La Campería Malaguita" en Paseo de Sancha (Málaga) que **no** es este local; no mezclar datos.

# Taberna Lang

Landing local para Taberna Lang, taberna de tapas y picoteo en Calle Jaén, 3, Rincón de la Victoria (Málaga).

## Comandos

- `bun run dev` — servidor Astro local.
- `bun run test` — pruebas locales de datos y contenido.
- `bun run check` — validación Astro.
- `bun run typecheck` — comprobación de TypeScript.
- `bun run build` — generar sitio estático.

## Datos públicos usados

- Nombre: Taberna Lang.
- Dirección: Calle Jaén, 3, 29730 Rincón de la Victoria (Málaga).
- Teléfono: +34 605 97 99 06.

No se incluyen horarios ni valoraciones.

## Sobre la foto

La URL de Google Maps facilitada es **solo la ficha del lugar** y no contenía ninguna foto
(le faltaba el segmento `!6shttps://lh3.googleusercontent.com/...`). Por eso este sitio **no
hotlinkea ninguna imagen** y resuelve el hero con tipografía y una tarjeta de información.
Si quieres añadir una foto real, pega la URL de la imagen y se incorpora al hero (y a
`og:image` / `twitter:image`).

La URL canónica (`https://taberna-lang-malaga.vercel.app`) es provisional: cámbiala si el sitio
se despliega en otro dominio, y actualiza también `public/robots.txt` y `astro.config.mjs`.
